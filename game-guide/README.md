# 똑... 똑... 똑... 모바일 게임 설명서

`index.html`을 열면 실행됩니다. GitHub Pages 등 정적 호스팅에도 그대로 올릴 수 있습니다.

최종 통합 퇴고본의 게임 준비, 조사 카드 운영, 최종 추리, 투표, 엔딩·점수 규칙을 반영했습니다.

제1막은 10분짜리 조사·논의를 담당자를 바꾸며 총 5회 진행합니다. 5회차 종료, 다섯 명의 조사 담당 완료, 공개 카드 10장을 모두 확인한 뒤 제2막으로 넘어갑니다.

`PretendardVariable.woff2`가 포함되어 있어 인터넷 연결 없이도 모든 글자가 Pretendard로 표시됩니다. 같은 폴더의 파일을 삭제하거나 옮기지 마세요. 글꼴 라이선스는 `Pretendard_LICENSE.txt`에서 확인할 수 있습니다.
