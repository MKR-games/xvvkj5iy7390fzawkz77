# 똑... 똑... 똑... 모바일 게임 설명서

`index.html`을 열면 실행됩니다. GitHub Pages 등 정적 호스팅에도 그대로 올릴 수 있습니다.

최종 통합 퇴고본의 게임 준비, 조사 카드 운영, 최종 추리, 투표, 엔딩·점수 규칙을 반영했습니다.

최종 구성은 QR카드 7장, 캐릭터 카드 5장, 조사 카드 13장, 개인 소지품 카드 5장으로 총 30장입니다. 별도의 MAP 카드와 주석 카드는 사용하지 않습니다.

제2막의 자기 소지품 선택 금지, 선택 뒤 교환·양도 금지, 확인 후 뒷면 보관을 명시했습니다. 조사에서 선택되지 않은 3장은 소지품 소유자의 사전 확인 권한과 충돌하지 않도록 ‘미확인’이 아니라 ‘미선택’ 카드로 정의했습니다.

이야기의 배경은 최종 타임라인과 공개 단서에 맞춘 장문 서사로 교체했습니다. 식사 시점, 바깥 걸쇠 구조, 시신의 공개 상태, 서술 시점과 불필요한 회의실 물품을 정리해 기존 조사 카드와 충돌하지 않도록 했습니다.

제1막과 제2막의 시작 부분에 ‘조사 가능 카드 = 조사 카드 13장 + 개인 소지품 카드 5장’ 정의를 반복 표기했습니다. 조사 카드만 선택해야 한다는 오해를 막기 위해 각 단계 문장에도 두 카드 종류를 직접 명시했습니다.

제1막은 10분짜리 조사·논의를 담당자를 바꾸며 총 5회 진행합니다. 5회차 종료, 다섯 명의 조사 담당 완료, 공개 카드 10장을 모두 확인한 뒤 제2막으로 넘어갑니다.

`PretendardVariable.woff2`가 포함되어 있어 인터넷 연결 없이도 모든 글자가 Pretendard로 표시됩니다. 같은 폴더의 파일을 삭제하거나 옮기지 마세요. 글꼴 라이선스는 `Pretendard_LICENSE.txt`에서 확인할 수 있습니다.
