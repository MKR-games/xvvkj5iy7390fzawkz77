# 《똑… 똑… 똑…》 민도겸 모바일 캐릭터 설정서

## 실행 방법

1. ZIP 파일의 압축을 풉니다.
2. 최상위 폴더의 `index.html`을 엽니다.
3. 인터넷 연결 없이 사용할 수 있습니다.

## 포함 기능

- 모바일 반응형 민도겸 캐릭터 설정서
- 왼쪽 상단 게임 설명서 바로가기
- 오른쪽 상단 글자 크기 조절: 가− / 가＋
- 오른쪽 상단 목차 빠른 이동
- 오른쪽 상단 MAP 팝업·확대·축소·스크롤
- 하단·우측 맨 위로 이동
- 시작 확인 뒤 상단 버튼을 안내하는 첫 실행 튜토리얼
- 최신 게임 설명서 함께 보기
- 게임 설명서 확인 후 읽던 위치로 복귀
- 키보드 초점·오프라인 저장 오류 대응
- Pretendard 글꼴 오프라인 포함
- 통합 퇴고본 타임라인 개선 기준의 구간형 행동표

폴더 구조를 변경하면 게임 설명서 연결이 끊길 수 있으므로, 압축을 푼 뒤 파일과 폴더를 그대로 유지해 주세요.

튜토리얼은 같은 브라우저·사이트에서 처음 한 번만 나타납니다. 첫 표시 시 기록을 저장하므로 닫기, 새로고침, 재접속 후에는 반복하지 않습니다. 같은 사이트의 다섯 캐릭터가 기록을 공유합니다. 브라우저의 사이트 데이터를 지우거나 저장 기능을 차단한 환경에서는 다시 표시될 수 있습니다.
